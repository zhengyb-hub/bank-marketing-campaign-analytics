## Key Results

- Campaign contacts analyzed: 41,188
- Conversions: 4,640
- Overall conversion rate: 11.3%
- Propensity model AUC: 0.80
- Estimated ROI assumption: EUR 3 per contact attempt and EUR 650 value per conversion

## Methods

- Campaign KPI analysis
- Segment conversion analysis
- Contact method and contact frequency analysis
- Propensity scoring for targeting
- ROI and cost-per-conversion modeling
